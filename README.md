# 🏋️ Club Deportivo Mobile

<p align="center">

  <img src="img/logo_icon-playstore.png" alt="Logotipo Club Deportivo" width="150"/>
</p>
Aplicación móvil desarrollada en Android Studio (Kotlin) para la gestión integral de un club deportivo: administración de socios, cobro de cuotas, seguimiento de deudores y asignación de actividades.


## 🚀 Características principales

* **Gestión de Socios:** Registro, modificación y consulta de datos.
* **Control de Cuotas:** Verificación de vencimientos y lista de socios deudores.
* **Carnet Digital:** Generación y visualización del carnet de socio.
* **Cobros:** Registro y emisión de comprobantes de pago.


---

## 🛠️ Tecnologías utilizadas

* **Lenguaje:** Kotlin
* **IDE:** Android Studio
* **Interfaz de usuario:** XML Layouts & Material Design
* **Control de versiones:** Git & GitHub

---

## ⚙️ Requisitos e Instalación

1. **Clonar el repositorio:** bash git clone https://github.com/br1an17/ClubDeportivoMobile.git
2. **Abrir en Android Studio:**
* Seleccionar `Open` y buscar la carpeta del proyecto.
3. **Sincronizar Gradle:**
* Permitir que las dependencias se descarguen automáticamente.
4. **Ejecutar:**
* Seleccionar un emulador o dispositivo físico y presionar `Run` (▶️).
